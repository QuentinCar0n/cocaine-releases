# Cocaine releases

Release builds of Cocaine, a menu bar app that keeps your Mac awake for a set time, with an optional mouse and trackpad scroll reverser.

This repo only holds the release zips. Installed copies of Cocaine check it once a day and update themselves.

## Install

Download the latest `Cocaine-<version>.zip` from [Releases](../../releases/latest), unzip it and move `Cocaine.app` to Applications. The app is not notarized, so right-click it and choose Open the first time.
